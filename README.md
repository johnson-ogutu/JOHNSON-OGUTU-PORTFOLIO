# Johnson Ogutu — Professional Portfolio

Static HTML/CSS/JavaScript portfolio for Ogutu Johnson Omondi.

## Included
- Home, About, Skills, Experience, Projects, Systems, Analytics, Teaching, Certificates, CV and Contact pages
- Responsive navigation and light/dark theme
- Professional CV and profile photo
- Relevant certificate and Diploma academic evidence
- LinkedIn and GitHub links
- Direct email and phone links
- CloudSchool school-portal administration included under Systems
- Teaching role at Nakuru College of Health Sciences and Management
- Project briefs with LinkedIn profile link
- Privacy-conscious public descriptions; no credentials, confidential records or referee phone numbers

## Run locally
Open `index.html` with VS Code Live Server.

## Publish
Upload the folder to GitHub Pages, Netlify, Vercel static hosting or another static web host. Keep the folder structure unchanged so relative links continue to work.

## Important
This version is intentionally static. There is no backend, database or admin control panel.
